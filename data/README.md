# Data

Raw data is not committed. The notebook downloads it into `data/raw/` on first run.

Source: [Diabetes 130-US Hospitals, 1999 to 2008](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008) (UCI Machine Learning Repository, CC BY 4.0). 101,766 real, de-identified inpatient encounters from 130 US hospitals.
